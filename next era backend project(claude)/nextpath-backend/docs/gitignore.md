# `.gitignore` — new file

Wasn't part of Codex's original file set, but is needed as soon as anyone runs `pnpm install` or `pnpm dev`/`pnpm build` in the project, since those commands create files that should never be committed.

## What's excluded and why
- **`node_modules/`** — installed dependencies; reproducible from `package.json` + `pnpm-lock.yaml`, so committing it would just bloat the repo.
- **`.next/`, `out/`** — Next.js's build output; regenerated by `pnpm build`.
- **`.env`, `.env.local`, `.env*.local`** — real environment values (the actual Supabase URL/key for the team's project). Only `.env.example` (the template, no real secrets) is meant to be committed.
- **`.DS_Store`, `*.log`** — editor/OS noise that varies by machine.
- **`*.tsbuildinfo`** — TypeScript's incremental build cache.
- **`next-env.d.ts`** — auto-generated by Next.js on `dev`/`build` to wire up its ambient types; safe to regenerate rather than commit.
